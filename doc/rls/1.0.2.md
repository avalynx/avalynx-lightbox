## Release 1.0.2 – Changelog Summary

Version 1.0.2 focuses on polish and project hardening: cleaner constructor code, improved packaging/export behavior, and a more reliable test/coverage pipeline. It also expands documentation (including a German README) to make adoption easier across teams.

* **Version Bump & Metadata Updates**
All version references were updated to 1.0.2 across the project.
Helps consumers and tooling consistently pick up the correct release.

* **Constructor Readability Cleanup**
Refactored the `AvalynxLightbox` constructor to reduce noise and improve clarity.
Makes the codebase easier to maintain and safer to extend.

* **Improved Module Packaging (CommonJS Export)**
Added a guarded `module.exports` path (and excluded it from coverage via Istanbul ignore).
Improves compatibility for environments that still rely on CommonJS imports.

* **CI Test Pipeline via GitHub Actions**
Introduced a `tests.yml` workflow to run tests on pushes/PRs using Node.js 20 and `npm ci`.
Gives users higher confidence that releases stay stable over time.

* **Coverage Reporting & Quality Gates**
Added Jest coverage collection and strict global thresholds (100%) with lcov/html outputs and Codecov upload.
Ensures regressions are caught early and encourages high-quality contributions.

* **Dependency Locking for Reproducibility**
Added `package-lock.json` and adjusted `.gitignore` to keep it tracked while ignoring coverage output.
Makes installs deterministic across machines and CI environments.

* **Documentation Enhancements (EN + DE)**
Added `README.de.md` and refreshed badges/links and versioned jsDelivr snippet in `README.md`.
Improves onboarding and makes it easier to adopt the library correctly.

* **Example Source Usage Update**
Updated the example page to reference the local source file instead of a pinned CDN version.
Makes local development/testing against the repo code more straightforward.
**Compatibility**: Backward compatible
