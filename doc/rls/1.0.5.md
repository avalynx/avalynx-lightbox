## Release 1.0.5 – Changelog Summary

This release focuses on a small but important visual fix to improve layering behavior of the lightbox, along with version consistency updates across the project. It ensures more reliable rendering in real-world layouts.

* **Improved Z-Index Handling**
Added a `z-index` rule to the lightbox container.
This ensures the lightbox reliably appears above other elements, avoiding display issues in complex layouts.

* **Consistent Version Updates**
Updated version references across source files, build output, and documentation.
Keeps all distributed assets aligned and avoids confusion when integrating via CDN or local builds.

* **Documentation Sync**
Updated CDN links in README files to reflect the new version.
Ensures users copy correct, up-to-date integration snippets.
**Compatibility**: Backward compatible
