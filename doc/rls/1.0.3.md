## Release 1.0.3 – Changelog Summary

This release introduces major new features including a fully functional gallery mode and background scroll prevention. It also shifts styling to a dedicated CSS file for better customization and provides comprehensive project guidelines for developers.

* **Gallery Mode**: Added support for navigating through multiple images using on-screen navigation buttons or keyboard arrow keys.
Users can now browse through image sets with automatic wrap-around functionality.
* **Background Scroll Prevention**: Implemented a feature to lock background scrolling while the lightbox is open, including automatic scrollbar width compensation.
This ensures a stable viewing experience without content jumping when the lightbox is toggled.
* **Dedicated CSS Styling**: Migrated lightbox styling from inline JavaScript to an external CSS file (`avalynx-lightbox.css`).
This allows for easier theme customization and cleaner JavaScript code.
* **Enhanced Configuration**: Introduced new options for `gallery` and `allowBackgroundScrolling`, plus customizable labels for navigation buttons.
Provides developers with more control over the lightbox behavior and internationalization.
* **Keyboard Accessibility**: Expanded keyboard support to include `ArrowRight` and `ArrowLeft` for gallery navigation and `Escape` for closing.
Improves usability for power users and ensures better accessibility compliance.
* **Project Guidelines**: Added new documentation files (`AGENTS.md`, `.junie/guidelines.md`, etc.) to standardize development workflows and quality requirements.
Ensures consistent code quality and 100% test coverage for all future contributions.
* **Expanded Examples**: Created new example pages for gallery mode and background scroll prevention to demonstrate the new capabilities.
Helps developers quickly understand and implement the new features in their own projects.**Compatibility**: Backward compatible (Note: You must now include the avalynx-lightbox.css file in your project).
