## Release 1.0.4 – Changelog Summary

This release focuses on build process refinements and packaging improvements, ensuring cleaner distribution and easier integration. It enhances how CSS is handled and improves overall package metadata for better compatibility with modern tooling.

* **Improved Build Process**
The build pipeline has been reorganized to better separate JavaScript and CSS steps.
This results in more predictable outputs and smoother integration into automated workflows.

* **Enhanced CSS Packaging**
CSS is now handled later in the build process and explicitly included in distribution files.
Users benefit from more reliable styling availability when installing via package managers or CDNs.

* **Added `style` Field in package.json**
A `style` entry now points directly to the distributed CSS file.
This improves compatibility with bundlers and tooling that automatically detect styles.

* **Refined Distribution Files सूची**
CSS files are now explicitly listed in the `files` array.
Ensures all required assets are included when publishing or installing the package.

* **Version Reference Updates**
All source, distribution, and documentation files now consistently reference version 1.0.4.
Reduces confusion and guarantees alignment across environments.

* **Documentation CDN Update**
Updated examples to use the latest version via GitHub-linked CDN references.
Helps users quickly adopt the newest release without manual version adjustments.
**Compatibility:** Backward compatible
