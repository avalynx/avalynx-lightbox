## Release 1.0.1 – Changelog Summary

A stability and DX-focused update: adds a comprehensive Jest test suite, hardens option/language handling, and streamlines builds and local development. Minor housekeeping keeps the repo tidy and examples in sync.

* **Comprehensive Test Suite**
Added 40+ Jest tests with jsdom environment and Babel transform.
Improves reliability, prevents regressions, and gives contributors fast feedback.

* **Stronger Input Validation**
Gracefully handles `null`/non-object `options` and `language` arguments.
Prevents runtime errors and makes the API more forgiving in real-world usage.

* **Bootstrap Integration**
ESM build now imports Bootstrap explicitly; dependency declared in package metadata.
Ensures consistent behavior when bundling and avoids missing peer issues.

* **Build Script Refinements**
ESM output is cleaned up (explicit import, removed CommonJS footer); UMD keeps `module.exports`.
Produces clearer, purpose-specific bundles for modern and legacy consumers.

* **Developer Environment Upgrades**
Docker image updated to PHP 8.3 with Node 18 and Yarn; utility tools added.
Speeds up local setup and aligns the stack with current tooling.

* **Project Hygiene**
Added `.gitignore` entries and removed `package-lock.json`.
Reduces noise in diffs and avoids accidental lockfile churn.

* **Documentation & Examples Synced**
README and example HTML now reference `1.0.1` CDN URLs.
Lowers copy-paste mistakes and guarantees users load the latest build.

* **NPM Scripts & Config**
Introduced `npm test` with `jest.config.js`.
Makes running the suite a one-liner for contributors and CI.
**Compatibility**: Backward compatible.
