## Release 1.0.0 – Changelog Summary

This milestone marks the first stable release of **AvalynxLightbox**, bringing version alignment, documentation improvements, and expanded installation options. The focus is on clarity, integration flexibility, and overall project maturity.

* **Stable 1.0.0 Release**
Promotes AvalynxLightbox to a stable release for production use.
Ensures consistent behavior and versioning across all distributed files.

* **Symfony AssetComposer Integration**
Added installation instructions for Symfony AssetComposer users.
Simplifies integration into Symfony projects and asset-managed environments.

* **Documentation Enhancements**
Expanded README with clearer setup examples and new installation paths.
Helps developers quickly configure the library regardless of their tech stack.

* **Version Synchronization**
Updated all references (source headers, package metadata, examples, CDN URLs) to `1.0.0`.
Guarantees users load the correct build everywhere.

* **Changelog Cleanup**
Removed the legacy `CHANGELOG.md` file to streamline repository maintenance.
Encourages use of release-based changelogs for consistency.
**Compatibility**: Backward compatible.
